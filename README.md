# Сервис управления рассылками

Веб-приложение для управления email-рассылками, разработанное на Django.

## Функциональность

### Часть 1: Разработка сервиса
1. **Управление клиентами** - CRUD операции для получателей рассылки
2. **Управление сообщениями** - CRUD операции для шаблонов сообщений
3. **Управление рассылками** - CRUD операции для рассылок с валидацией
4. **Отправка сообщений** - Ручной запуск рассылок через интерфейс
5. **История попыток** - Отслеживание успешных/неуспешных отправок
6. **Главная страница** - Статистика по всем рассылкам

### Часть 2: Расширение функциональности
7. **Регистрация и аутентификация** - Пользовательские аккаунты
8. **Статистика и отчеты** - Детальная аналитика по рассылкам
9. **Ограничение доступа** - Ролевая модель (Пользователь/Менеджер)
10. **Кеширование** - Серверное кеширование для повышения производительности
